# AI Study Buddy

AI Study Buddy is a simple student-focused web application developed as a SmartBridge project.

## Features
- Responsive student-friendly dashboard
- Quick study notes with browser local storage
- Practice quiz
- Study task planner
- Progress tracking
- Works directly on GitHub Pages

## Technologies
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run
Open `index.html` in a browser, or enable GitHub Pages for the repository.
